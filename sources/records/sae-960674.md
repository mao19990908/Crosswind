## Physical problem and method
- Track-mounted moving model traverses an atmospheric-boundary-layer wind-tunnel working section; three basic model configurations.
- Same nominal wind input compared between static yaw and dynamic traverse.
- Scale, Reynolds number, gust edge, turbulence, coordinates and normalization: not reported in abstract.

## Results / validation / evidence
- Below 15° yaw static and dynamic data compare well; above 15° after large-scale separation, dynamic forces/moments exceed static values.
- Peak magnitude, phase, uncertainty: not reported in abstract.
- Evidence: SAE abstract.

## Limitations / relevance / follow-up
- Limitation: the 15° observation is facility/configuration-specific and not a universal threshold.
- Relevance: explicit steady-yaw → dynamic-gust comparison node.
- Follow-up: full-text extraction of gust profile, model geometry, force definitions and uncertainty; cited-by chain.
