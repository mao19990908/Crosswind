# 航向、侧偏与相对来流：显式坐标下的平面运动学（2026-10-19）

**ANALYST_INFERENCE**。以下是本库选择并完全声明坐标后的向量恒等式，不是从某一作者处抄出的通用符号公式，也不恢复缺失的CFD/车辆接口。它把已有的角度区分与相对速度证据连起来；81条source claims及其等级不改。

## 约定先于公式

- 地面系g和车体系b均取右手系、z向上；车体x向前、y向左，地面X/Y是任意固定水平参考轴。
- ψ是车体x轴相对地面X轴的逆时针航向角；R(ψ)把车体系分量转到地面系。
- v是**同一个车辆参考点**相对地面的速度，u_b=(u_x,u_y)=Rᵀv_g。w_g是指定入流/环境风场在同一位置、时刻的空气地面速度，方向指空气流向，不是气象“风从哪里来”的方位；不把车表面流速或另一位置探头数据自动当作它。
- 定义a_b=Rᵀ(v_g−w_g)：车辆相对空气的速度。空气相对车辆的流速则为−a_b；混用两者会引入180°方向差。
- 本页自定义α_a=atan2(a_y,a_x)。它是上述车辆穿过空气的方向在车体系中的角度；作者所谓aerodynamic yaw的符号/轴必须另外映射，不直接改名套用。

角度内部用rad；下表和CSV显示deg。速度均m/s。当前仅处理水平平动/航向，没有把它当作含侧倾/俯仰/角速度诱导局部速度的三维车身流场。

## EQ-RELWIND-PLANAR：向量与三个角

\[
R(\psi)=\begin{bmatrix}\cos\psi&-\sin\psi\\\sin\psi&\cos\psi\end{bmatrix},\qquad
\mathbf a_b=\mathbf u_b-R^T\mathbf w_g.
\]

\[
\beta_v=\operatorname{atan2}(u_y,u_x),\quad
\chi=\operatorname{atan2}(v_{g,Y},v_{g,X}),\quad
\alpha_a=\operatorname{atan2}(a_y,a_x).
\]

β_v是该参考点的**地速方向相对车体**的角，χ是地面航迹方向；非零地速下χ=wrap(ψ+β_v)。ψ由姿态定义，不要求车辆正在平移。α_a取决于车辆速度和风速之差，通常既不等于ψ，也不等于β_v。无地面风且速度非零时α_a=β_v，是本约定的特例，不是三种角永远相等。

分量展开为

\[
a_x=u_x-(\cos\psi\,w_X+\sin\psi\,w_Y),\qquad
a_y=u_y-(-\sin\psi\,w_X+\cos\psi\,w_Y).
\]

不能只把航向ψ从某个未说明参考系的“风向角”中减去，也不能把横风标量直接与u_y相加。先统一向量的坐标、参考点和“流向/来向”约定，再求差与atan2。

当|u_b|=0时β_v和χ没有速度方向定义；当|a_b|=0时α_a没有定义，即使某个编程库对atan2(0,0)返回0也不填成物理零角。非零但接近零时方向对输入误差敏感；本文没有替真实数据设定有效性阈值。逆风/顺风跨越a_x=0时还要保留象限，单值atan(a_y/a_x)不能替代atan2。

## 八个可复算的分析者例子

[CSV](relative_wind_examples.csv)包含所有输入与输出，全部标记SYNTHETIC_ANALYST_INFERENCE，不代表实验、CFD或驾驶员数据。地面风始终是“流向”向量。

| 例子 | ψ；u_b；w_g | β_v / χ / α_a（deg） | 要区分的量 |
|---|---|---|---|
| 无风直行 | 0；(20,0)；(0,0) | 0 / 0 / 0 | 基准 |
| 地面横风 | 0；(20,0)；(0,5) | 0 / 0 / −14.0362 | 无车辆侧偏仍有相对风角 |
| 同一地面风，转向另一航向 | 90；(20,0)；(0,5) | 0 / 90 / 0 | 此时风成为沿车轴的顺风，穿空气速度15m/s |
| 无风且侧偏5° | 30；20(cos5°,sin5°)；(0,0) | 5 / 35 / 5 | 航向、航迹、侧偏的角色不同 |
| 侧偏但相对风角为0 | 0；(20,2)；(0,2) | 5.7106 / 5.7106 / 0 | 不能从侧偏角直接替代气动角 |
| 顺风快于车辆 | 0；(20,0)；(25,0) | 0 / 0 / 180 | 数学象限例，不能据此外推作者小角/前向气动模型 |
| 相对空气速度为0 | 0；(20,0)；(20,0) | 0 / 0 / 未定义 | 不把atan2(0,0)当有效风角 |
| 车辆地速为0但有风 | 0；(0,0)；(0,5) | 未定义 / 未定义 / −90 | 姿态可知不等于速度方向可知 |

每行都核对预先写出的a_b期望向量，并将地面风向量和航向共同施加37°整体旋转后重算，确认车体系相对速度不变。1e-12仅为这些合成浮点计算的一致性容差，不是物理速度阈值或仪器不确定度。

下面的标准库代码可从CSV输入列重新计算核心输出；角度无定义时返回None。CSV中同名输出列可据此逐项核对。

```python
import math

def angles(psi_deg, ux, uy, wx, wy):
    p = math.radians(psi_deg)
    c, s = math.cos(p), math.sin(p)
    ax, ay = ux - c*wx - s*wy, uy + s*wx - c*wy
    vx, vy = c*ux - s*uy, s*ux + c*uy
    angle = lambda y, x: math.degrees(math.atan2(y, x))
    return {
        "a_x": ax, "a_y": ay,
        "ground_speed": math.hypot(ux, uy),
        "air_speed": math.hypot(ax, ay),
        "beta_v_deg": angle(uy, ux) if math.hypot(ux, uy) else None,
        "course_deg": angle(vy, vx) if math.hypot(ux, uy) else None,
        "alpha_deg": angle(ay, ax) if math.hypot(ax, ay) else None,
    }
```
