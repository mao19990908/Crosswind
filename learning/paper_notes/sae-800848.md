## Full-text Pass 2 completed (2026-09-25)

Old abstract-only note superseded. SAE article pp.1–12 uses five instrumented vehicles at the NHTSA/STI nominal 35 mph / 120 ft fan facility. It separates fixed steering, free steering and active-driver closed loop at 50 mph; the latter cannot be used as an open-loop transfer measurement. Table 1 is calculated *steady* yaw, Table 3 measured *peak* response. VW Microbus fixed-steer prediction 6.01°/s versus measured peak 4.71±0.41°/s (7 runs), so the simplified model's apparent numerical error is real but not a same-statistic transient comparison. Table 4/Fig.5 subjective ratings have few drivers and support only an exploratory demand relation. Wind-tunnel aero coefficients, tire data and center-of-force geometry feed a steady yaw predictor; the 2 s gust shows little yaw-rate overshoot *within these conditions*. Paper p.12 reference 1 directly identifies `dot-hs-805-079` as underlying technical report, and the article is a partial analysis of that project. Evidence `E-1980-01/02/03`; Pass 2 complete, no high-wind extrapolation promoted to measured validation.
