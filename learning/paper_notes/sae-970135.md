## Full-text Pass 2 completed (2026-09-25)

The preceding abstract-only note is superseded. SAE PDF article pp.31–34 / Figs.3–9 verifies the Cranfield squareback track, four turbulence grids (nominal freestream TI 1–3.5%), five vertical profiles, and 12–18 m/s traverse. The grid comparison shows little load response except a horizontal-bar case; it was not atmospheric-turbulence scaled. Roughness-board profiles alter turbulence as well as mean shear, so the observed front/rear lift and yaw-moment changes cannot isolate shear causally. Dynamic reference speed changes yaw **and** resultant pressure, whereas static normalization changes pressure only. Seven alternatives fail to collapse every load; a height mean improves lift alone. No independent Level B transient validation or Level C motion. Evidence `E-1997-01/02`; direct source reference to SAE 960674 p.34.
