# CFD：先核对阵风实现

`sae-970404` 摘要包含一厢车进入侧风区及会车场景、滑移网格、ALE 和 k–ε 模型；其试验比较的量和网格/时步收敛细节仍需全文。`jcp-2016-tunay` 全文确认 IDDES、overset 与车辆运动耦合。两者的物理输入和车辆反馈不同，不能仅按湍流模型复杂度排序。

| 项目 | `sae-970404` | `jcp-2016-tunay` |
|---|---|---|
| gust implementation | 车辆进入侧风区，具体边界待核 | 名义5L、1.5L余弦边沿；零点待P3核对 |
| vehicle motion | ALE/滑移网格，运动自由度待核 | 单轨车辆侧向/横摆反馈 |
| turbulence model | k–ε | IDDES |
| mesh/time resolution | 见下方既有全文更新 | 24M单元；6e-5s气动尺度 |
| validation A/B/C | 摘要称与试验气动特性比较，等级待核 | GTS阻力+12%；CG趋势，非实测整车验证 |

每篇 CFD 后续按风场 A、气动 B、车辆运动 C 分开登记；“与试验一致”不足以自动得到 Level C。
### 1997 移动边界 CFD 的核验层级（2026-09-25）

Okumura/Kuriyama `sae-970404` 全文采用不连续接口滑移网格与 ALE，约25万单元的 k–ε/MUSCL 模型模拟单厢车进入横风区；同文另算相对速度 11.1 m/s 的两车会车。横风算例的预测横摆峰位置约 `X/L=1.4`，侧力没有对应尖峰，但无网格收敛或独立载荷时程验证。风挡板算例的数值横摆力矩下降和实车横摆角速度下降都约20%，量纲/指标不同。会车“近两倍静态峰值”的外部对照用大巴与轿车，不与数值两单厢车几何匹配。故方法谱系可作为早期移动边界 CFD 节点，验证等级须保守。

## 模型尺度和验证不能混写（2026-10-09）

Winkler2016使用1/8模型91.6m/s、Re2e6，车辆动力学全尺度25m/s，Eq1–3按Cs/Cyaw/St换算载荷与时间；不能把CFD步长6e-5s直接用作全尺寸动力学步长。IDDES/overset2400万单元中的900万属于重叠域。原文网格调整未改善GTS阻力高估12%，几何差异尚存，因此不声明网格独立或匹配瞬态验证。E-2016-02/04。
