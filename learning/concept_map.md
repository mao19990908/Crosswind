# 概念地图

```text
风输入：自然风 / 标准发生器 / 风洞阵风 / CFD 边界
  → 相对来流（速度、相对偏航角、空间与时间尺度）
  → 非定常流场（分离、尾流、表面压力）
  → 气动侧力 / 横摆力矩 / 升力 / 侧倾力矩
  → 车辆横向 / 横摆 / 侧倾响应
  → 驾驶员或控制器修正
  → 轨迹与稳定性评价
```

一条箭头表示要研究的因果接口，不表示现有 22 条资料已经逐级验证。具体已核验的关系在 `graph/edges.csv`；缺失处写入 `open_questions.md`。

- 风输入形式之间不能机械互换。`dot-hs-805-078` 的有限风区/脉冲、`pimeche-2001-passmore` 的正弦输入、`sae-530255` 的道路阵风是不同输入问题。
- 固定偏航稳态气动数据可以形成基线。`sae-960674` 直接比较静态与移动模型动态值；该试验观察到的约 15°分界只属于其三种模型配置和名义风输入。
- `pimeche-2001-passmore` 显示正弦输入下侧力与横摆力矩不宜合成一个统一倍率。把此观察推广到所有波形是 `ANALYST_INFERENCE`，不作为结论。
- Level A 风场、Level B 载荷、Level C 车辆运动分别验证。`sae-06-14-01-0001` 提供 A/B 的摘要级证据；`sae-2017-01-1515` 提供 C 的摘要级对照；两篇并非同一试验，不能拼成多级联合验证。
