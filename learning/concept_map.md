# 概念地图

```text
风输入：自然风 / 标准发生器 / 风洞阵风 / CFD 边界
  → 相对来流（速度、相对偏航角、空间与时间尺度）
  → 非定常流场（分离、尾流、表面压力）
  → 气动侧力 / 横摆力矩 / 升力 / 侧倾力矩
  → 车辆横向 / 横摆 / 侧倾响应
  → 驾驶员或控制器修正
  → 轨迹与稳定性评价
```

一条箭头表示要研究的因果接口，不表示现有25条资料已经逐级验证。具体已核验的关系在 `graph/edges.csv`；缺失处写入 `open_questions.md`。

- 风输入形式之间不能机械互换。`dot-hs-805-078` 的有限风区/脉冲、`pimeche-2001-passmore` 的正弦输入、`sae-530255` 的道路阵风是不同输入问题。
- 固定偏航稳态气动数据可以形成基线。`sae-960674` 已核E2中前升力和横摆峰约15°后出现差异、侧力约30°后偏离；均值/峰值与分量分别保留，不能凝成一个通用15°阈值。
- `pimeche-2001-passmore` 显示正弦输入下侧力与横摆力矩不宜合成一个统一倍率。把此观察推广到所有波形是 `ANALYST_INFERENCE`，不作为结论。
- Level A风场、Level B载荷、Level C车辆运动分别验证。`sae-06-14-01-0001` 仍为A/B摘要级证据；`sae-2017-01-1515` 已有E2的部分风场/三车固定转向分指标对照。两篇非同一试验，不能拼成完整多级验证链；旧摘要claim保持各自等级。

## 从测量与计算到响应的两类接口

压力积分/相位平均连接实验观测与载荷；空间/时间格式、网格接口连接数值离散与载荷。二者各有带宽、配准或数值分辨率的边界，不能由峰值吻合替代逐环节核查。见[实验方法](06_experimental_methods.md)及[CFD](07_transient_cfd.md)。

M-OVERSET/M-SLIDING-ALE是移动网格能力；M-ONEWAY-MBD/M-IDDES-2WAY/M-ALE-6DOF分别包含不同实际反馈架构。C-COUPLING-SCHEDULE与C-NUMERICAL-RESOLUTION是显式分析框架，帮助定位时刻/保持/插值和收敛证据缺口，不代表恢复了作者代码或新增验证定律。见[耦合章节](08_aero_vehicle_coupling.md)及[四来源证据](audits/cfd_coupling_evidence.md)。
