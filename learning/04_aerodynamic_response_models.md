# 气动输入到载荷时程

直觉上，阵风到气动力不是只看某一时刻的风角；输入的变化速度可能影响载荷大小和相位。`sae-730232` 的摘要从气动导数和风梯度讨论瞬态项；`pimeche-2001-passmore` 的摘要用正弦输入比较侧力与横摆力矩的气动倍率。两者的数学定义尚未获得全文，不能拼成一个统一传递函数。

| 路线 | 已知输入 → 输出 | 当前证据 | 不能推定 |
|---|---|---|---|
| 气动导数 | 风角/梯度 → 侧力及横摆力矩的敏感量 | `sae-730232` E1 | 导数公式、适用线性范围 |
| 正弦响应 | 周期性横向风 → 侧力与横摆力矩幅值比较 | `pimeche-2001-passmore` E1 | 复数导纳、相位曲线、非线性或记忆模型 |
| 车辆动力学 ROM 接口 | 载荷时程 → 车辆运动 | 本库 `OPEN_QUESTION` | 现有两篇已实现 Level 3 耦合 |

工程迁移需要分别核验输入风场、每个载荷分量的幅相、参考面积/力臂、拟合参数和 Level C 运动误差。公式在 `equations.md` 标为 `FORMULA_PENDING_FULLTEXT`；这不是否定路线，而是防止摘要关键词被误作可复现模型。
