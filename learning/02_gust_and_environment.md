# 阵风输入与环境

峰值侧风相同，入风边缘、持续长度、垂向廓线和频谱仍可能不同。比较前应先说明输入是时间信号、空间风区还是车辆运动造成的相对来流，并固定测量/车辆参考点。

| 输入 | 既有证据／发生方式 | 尺度与定义 | 当前可用边界 |
|---|---|---|---|
| 道路自然阵风 | Lay/Lett1953摘要；Brandt2023扩展正文道路测量 | 前者未给完整风时程；后者多类道路事件 | E1与章节E2分别保留，不能当同一种确定性波形 |
| 有限横风区 | Beauvais1967/Macklin1996约束移动车模；Ryan1998移动孔径；DOT1979全尺寸目录 | 试验段宽度、孔径、空间边沿和车辆长度分别记录 | 各源E2（DOT仍E1），不是统一矩形脉冲；见E-1967-03/04、E-1998-05 |
| 半余弦空间过渡 | Hucho1973 Eq23、E-1973-02 | sm/l=1–5；给定空间函数 | 输入公式已核；真实轮廓/动力学输出仍缺，不能继续称所有ramp均UNKNOWN |
| 规定有限空间风区 | Winkler2016，E-2016-02及全文审计 | 名义5L、升降沿1.5L；空间零点/实现未定 | full/model时间还需St相似缩放，不用CFD步长直接当整车时间 |
| 正弦横向输入 | Passmore2001摆动翼，E-2001-02至06 | k_m=pi*f*l/U；正文2–8Hz与图含1Hz差异保留 | 幅值、QS传播相位和低角度SNR分别记，不套用有限风区峰值比 |
| 垂向剪切／湍流 | Macklin1997格栅与粗糙板，E-1997-01/02 | 粗糙板同时改变平均廓线和湍流；参考速度也改变动压/风角 | E2条件结果，不能单独归因剪切或推到所有大气湍流 |
| 独立偏航／流向阵风／宽带 | SAE2025发生器，E-2025-02至04 | 偏航和流向速度扰动来自不同子系统 | 流向gust幅值不当作横风幅值；边际PDF/PSD相合不等于空间相干和整车响应验证 |
| 风发生器有限区 | Lewington2017三车与Nakasato2017 | 前者约16.6m；后者40m/33.3m/s约1.2s名义通过 | 两种设施、风形与车辆环路不同；不得互换原始输入 |

## 长度、边沿和驻留时间

**ANALYST_INFERENCE**：静止空间风场、恒定沿程速度且指定参考点时，s=V(t-t0)，边沿通过时间sm/V；V(t-t0)/l的过渡宽度为sm/l。它不代表全车暴露时间，也不代表载荷完成建立。上升时间还须注明0–100%、10–90%或作者定义；没有边沿参数时，保留UNKNOWN，不由试验段宽度自动反推。

不同车体位置先后入风造成的相位，与流场建立滞后、滤波/触发延迟和车辆动力学响应是不同机制。五车长风区内某些压力仍未稳态（E-2000-0876-03），因此不能把风区长度直接当作普适建立长度。

源内参数见[synthesis matrix](../synthesis/gust_parameter_matrix.csv)，源间输出指标见[comparison matrix](audits/gust_response_comparison.csv)。道路风、标准发生器、动态风洞与CFD入口的等效性需要同条件证据；ISO正文尚未取得，不能从目录填具体程序。
